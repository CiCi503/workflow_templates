# SHA256 验证工具 - 快速指南

## ✅ 已完成

为你创建了一个完整的 **模型 SHA256 验证工具**，用于检查下载的模型文件是否完整正确。

## 🚀 立即开始

### 1. 安装依赖

```bash
pip install huggingface_hub colorama
```

### 2. 验证模型

```bash
# 替换为你的模型目录路径
python3 verify_models_sha256.py /root/dehui/models
```

### 3. 验证特定目录

```bash
# 只验证 unet 目录
python3 verify_models_sha256.py /root/dehui/models --dir unet

# 只验证 loras 目录
python3 verify_models_sha256.py /root/dehui/models --dir loras

# 显示详细信息
python3 verify_models_sha256.py /root/dehui/models --dir unet --verbose
```

## 📋 工具功能

✅ **自动计算** - 计算本地文件的 SHA256 哈希值  
✅ **远程对比** - 从 Hugging Face 获取官方 SHA256  
✅ **智能报告** - 自动列出所有不一致的文件  
✅ **彩色输出** - 清晰易读的终端输出  
✅ **JSON 导出** - 可导出验证报告  
✅ **目录筛选** - 支持只验证特定目录

```bash

# 详细模式
python3 verify_models_sha256.py /path/to/models --verbose

# 导出报告
python3 verify_models_sha256.py /path/to/models --output report.json

```

## 🔄 完整工作流

```bash
# 1. 下载模型
python3 download_models_simple.py --dirs unet

# 2. 验证完整性
python3 verify_models_sha256.py ./models --dir unet

# 3. 如果发现损坏文件，删除并重新下载
rm ./models/unet/damaged_file.safetensors
python3 download_models_simple.py --dirs unet

# 4. 再次验证
python3 verify_models_sha256.py ./models --dir unet
```

## 💡 使用技巧

### 技巧 1: 下载后立即验证

```bash
./download_with_hf.sh --dirs loras && \
python3 verify_models_sha256.py /root/dehui/models --dir loras
```

### 技巧 2: 批量验证多个目录

```bash
for dir in unet loras vae clip; do
    python3 verify_models_sha256.py /root/dehui/models --dir $dir
done
```

### 技巧 3: 使用国内镜像

```bash
export HF_ENDPOINT="https://hf-mirror.com"
python3 verify_models_sha256.py /root/dehui/models
```

## ⚠️ 注意事项

1. **网络要求** - 需要能访问 Hugging Face（或配置镜像）
2. **验证时间** - 大文件需要几分钟计算 SHA256
3. **支持范围** - 目前只支持 Hugging Face 的模型
